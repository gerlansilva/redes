      Duplo mapa de áreas das revistas

      revistas que publicam o corpus e revistas citadas, por área
      Execute uma análise para ver o duplo mapa.

      Revista → área, para conferência (classificação aproximada por palavras do nome)
      Revista Área (aproximada) Termo que decidiu Citações feitas Citações recebidas Desenhada
      Esquerda: revistas que publicam os documentos do corpus; direita: revistas citadas por elas; faixa = citações entre áreas. A área é inferida por palavras do NOME da revista (aproximada): confira a tabela. Usa o corpus completo, não só o período.

      Similitude dos resumos

      palavras dos resumos que aparecem juntas, em blocos temáticos
      Execute uma análise para ver a similitude dos resumos.

        Palavras do grafo: frequência, bloco e grau
        Palavra Idioma Frequência Resumos Ocorrências Bloco Grau
        Cada ponto é uma palavra dos resumos (forma básica); linha cheia = árvore máxima dos laços mais fortes, tracejada = laços extras; cores = blocos temáticos. O idioma de cada resumo é detectado (en, pt, es) e palavras de idiomas diferentes não se juntam. Usa os resumos do corpus (do período escolhido).

        Sobre o Redes

        Uso, escopo e créditos da ferramenta.

        O que é

        Ferramenta em Python (NetworkX e NumPy), com interface web local, inspirada no SciMAT, no VOSviewer e no Gephi. Foi desenvolvida para as análises de uma pesquisa de doutorado.

        Importa corpus de Scopus, OpenAlex, Web of Science, RIS, BibTeX e CSV, monta as redes e os diagramas estratégicos e gera relatórios em HTML.

        Como usar
        1. Importe o corpusO projeto é gravado como .redes.
        2. Defina os períodosNa importação ou depois, na aba Períodos.
        3. Ajuste a análiseUnidade, matriz, similaridade e agrupamento.
        4. Explore e exportePré-visualize, rode a grade completa e gere o relatório HTML.

        Tudo roda na sua máquina; nenhum dado sai dela. Projetos antigos .scimat continuam abrindo.

        Como usar

        1. Abra o corpusAbra um projeto .redes ou .scimat, ou importe um arquivo da base.
        2. Ajuste, se quiserO modo simples escolhe a frequência mínima. Os demais parâmetros ficam no modo avançado.
        3. ExecuteNo modo simples a análise roda ao escolher o tema ou o período. No avançado, use "Pré-visualizar" ou "Grade completa".
        4. ExploreClique em um tema do Resumo para ver itens e documentos. As outras abas trazem rede, diagrama e comparação de períodos.
        5. ExporteBaixe a grade, os índices e as redes, ou gere o relatório HTML.
